# Stratified Sampling — VLE + IFT Batch Execution

Runs VLE and interfacial tension (IFT) calculations over stratified composition sets.
Compositions are generated by `STRATIFIED_SAMPLING.ipynb` and stored in `OUTPUT/`.
Calculations are executed by `VLE_IFT_V4.ipynb` via papermill on the HPC cluster.

---

## What Runs What

### `STRATIFIED_SAMPLING.ipynb`
Generates the input data. Samples CO2-rich multicomponent feed compositions using
stratified sampling and writes them to `OUTPUT/<SIZE>/trial_XX.csv`. Run this once
before any calculations.

### `VLE_IFT_V4.ipynb`
The calculation notebook. For a given trial CSV it:
- Loads all feed compositions from the file
- Computes VLE (bubble/dew curves) via PC-SAFT for each composition
- Computes interfacial tension via cDFT for each composition
- Writes tabular results to `CSV_FOLDER` and figures to `PLOT_FOLDER`

This notebook is never run manually in batch — it is always invoked by papermill
through `RUN_trial.sh`.

### `RUN_trial.sh`
Runs **one trial** (one CSV file) as a **SLURM array job** — one task per composition.
Takes `SIZE` and `TRIAL` as arguments, then:
1. Reads `OUTPUT/<SIZE>/<TRIAL>.csv` and counts the compositions (N)
2. Self-submits as a SLURM array `0-(N-1)`, where each task maps to one composition
   via `SLURM_ARRAY_TASK_ID` → `FEED_INDEX`
3. Each array task runs `VLE_IFT_V4.ipynb` for its single composition and writes to
   `RESULTS/<SIZE>/<TRIAL>/<ARRAY_JOB_ID>_<TASK_ID>/`

```
sbatch RUN_trial.sh N025 trial_03
# → submits array job with 25 tasks (one per composition in trial_03.csv)
```

### `MASTER_RUN.sh`
Runs **everything**. Loops over all 4 sizes and all 20 trials and calls
`sbatch RUN_trial.sh SIZE TRIAL` for each combination — submitting 80 array jobs,
each of which fans out into N individual composition tasks.

```
bash MASTER_RUN.sh
# → 80 array jobs → 5000 individual SLURM tasks total
```

### `clean.ipynb`
Scans `RESULTS/` across all sizes and trials, reports failures and missing tasks,
and combines successful results into `COMBINED/<SIZE>/trial_XX.csv`.

## Notebook Parameters (`VLE_IFT_V4.ipynb`)

| Parameter                      | Batch default  | Description                                            |
|--------------------------------|----------------|--------------------------------------------------------|
| `COMPOSITIONS_CSV`             | *(passed in)*  | Path to the trial CSV — set by `RUN_trial.sh`          |
| `FEED_INDEX`                   | `None`         | `None` → run all rows; integer → run one row (debug)   |
| `SLURM_RUN`                    | `True`         | Enables tight tolerances and dense grids for HPC       |
| `verbose`                      | `False`        | Print detailed intermediate output                     |
| `CSV_FOLDER`                   | *(passed in)*  | Output directory for tabular results                   |
| `PLOT_FOLDER`                  | *(passed in)*  | Output directory for figures                           |
| `CRITICAL_REGION_ENHANCEMENTS` | `False`        | Fine T-grid meshing near the critical point            |

`SLURM_RUN=True` activates: `P_TOL=1e-4`, `cDFT_NP=10`, `lgrid=200`, `ngrid=2000`.

## Full Workflow

```
bash MASTER_RUN.sh          # 1. submit all 80 array jobs (→ 5000 tasks)
        ↓  wait
run clean.ipynb             # 2. identify failures, combine successes → COMBINED/
        ↓
sbatch --array=<ids> \      # 3. rerun only failed task IDs (repeat until clean)
    RUN_trial.sh SIZE TRIAL
        ↓  wait
run clean.ipynb             # 4. confirm all done → COMBINED/ ready for ML
```

### Identifying and rerunning failures

`clean.ipynb` prints the exact task IDs that failed, e.g.:

```
=== Ran but failed (no CSV output) ===
  N025/trial_03  →  2 failed tasks: [7, 18]
  N050/trial_11  →  1 failed tasks: [34]
```

Resubmit only those task IDs using `--array` with a comma-separated list:

```bash
sbatch --array=7,18  RUN_trial.sh N025 trial_03
sbatch --array=34    RUN_trial.sh N050 trial_11
```

Each rerun creates new `<NEW_JOB_ID>_<TASK_ID>/` folders alongside the old failed
ones. `clean.ipynb` automatically picks the successful run for each task ID and
ignores the failed folders — no manual cleanup needed.

## Testing Before Full Batch

Use `N025/trial_00.csv` (smallest file, 25 compositions) and write to `test_out/`
so results don't mix with real `RESULTS/`.

**Step 1 — single composition** (fast, verifies the notebook runs end-to-end):

    -p CSV_FOLDER       "test_out/CSV" \
    -p PLOT_FOLDER      "test_out/PLOTS"

**Step 2 — full trial locally** (all 25 compositions, confirms batch logic works):

```bash
papermill VLE_IFT_V4.ipynb out_test.ipynb \
    -p FEED_INDEX       None \
    -p COMPOSITIONS_CSV "OUTPUT/N025/trial_00.csv" \
    -p SLURM_RUN        False \
    -p CSV_FOLDER       "test_out/CSV" \
    -p PLOT_FOLDER      "test_out/PLOTS"
```

**Step 3 — submit to SLURM** (once satisfied with local output):

```bash
sbatch RUN_trial.sh N025 trial_00
```
