# Active Learning — Composition Subset Selection

## Overview

This module implements **Algorithm 1** from Xiang et al. (*JCIM* 2023) to select small, informative composition subsets from a 1000-point candidate pool. Three sampling strategies are compared across ten sample budgets N ∈ {10, 20, …, 100}.

The key outputs — 30 CSV files containing selected compositions and their PC-SAFT bubble-point pressures — feed directly into the downstream cDFT T/P grid calculations.

## Design: Two-Phase Pipeline

### Phase 1 — Fit GPR Hyperparameters (once)

A GPR model (z → P_bubble) is fitted on pre-computed A2 data to learn ARD length-scales that encode compositional similarity. No PC-SAFT calls are needed here — A2 already contains P_bubble values.

| Step | Detail |
|---|---|
| Data source | `DATASET_A2/CombinedDataset_A2.csv` (94,469 rows) |
| Filter | 8-component rows only (extra z-columns < 1e-6) |
| Temperature | T_REF = 250 K (±1 K) |
| Kernel | ConstantKernel × Matérn-5/2 (ARD, 8 length-scales) + WhiteKernel |
| Max samples | 5,000 (random subsample if A2 has more after filtering) |
| Optimizer restarts | 3 |

After fitting, the **signal kernel** (ConstantKernel × Matérn, no noise) is extracted from `gpr.kernel_.k1` and frozen. Its ARD length-scales carry the compositional geometry used in Phase 2.

### Phase 2 — Algorithm 1 (pure kernel, no labels)

The frozen signal kernel drives a greedy diversity-maximising selection loop. **No P_bubble labels are needed during selection** — the algorithm measures how far each candidate is from the already-selected set in kernel space.

```
S ← randomly pick 2 points from pool M
P ← M \ S

while |S| < N_max and P ≠ ∅:
    T ← random subset of P of size min(|P|, N_t)     # evaluation budget
    U_T ← diag(K_TT − K_TS · K_SS⁻¹ · K_ST)         # kernel uncertainty
    α   ← argmax(U_T)
    if U_T[α] > u_t:
        S ← S ∪ {α};   P ← P \ {α}
    for β where U_T[β] < u_t:                         # "converged" → discard
        P ← P \ {β}
```

Snapshots of S are saved at each N ∈ {10, 20, …, 100}. Because S grows monotonically, **all AL subsets are nested** (the N=30 set contains the N=20 set as a strict prefix).

## Sampling Strategies

| Strategy | Method | Nested? |
|---|---|---|
| **AL** | Algorithm 1 — kernel-uncertainty greedy | Yes (by construction) |
| **Random** | One fixed permutation, take first N | Yes |
| **Stratified** | Proportional CO2-bin × mixture_size stratification | No |

All three strategies sample from the **same 1000-composition pool**.

### Stratified binning

| CO2 bin | Label |
|---|---|
| [0, 0.94) | < 0.94 |
| [0.94, 0.96) | 0.94–0.96 |
| [0.96, 0.97) | 0.96–0.97 |
| [0.97, 0.98) | 0.97–0.98 |
| [0.98, 0.99) | 0.98–0.99 |
| [0.99, 1.01] | ≥ 0.99 |

Allocation per stratum is proportional to stratum size, rounded to integers summing exactly to N.

## Kernel Uncertainty Formula

$$U_T = \text{diag}\!\left(K_{TT} - K_{TS}\, K_{SS}^{-1}\, K_{ST}\right)$$

| Symbol | Meaning |
|---|---|
| T | Candidate set (unevaluated pool rows) |
| S | Already-selected set |
| K_TT | (|T| × |T|) kernel matrix of candidates (diagonal only needed) |
| K_TS | (|T| × |S|) cross-kernel |
| K_SS | (|S| × |S|) kernel of selected set |

U_T[i] = 0 means point i is fully explained by S; high U_T means a novel composition far from everything already in S. A Cholesky solve is used for stability (fallback: `np.linalg.pinv`).

Pool features are **StandardScaler-transformed** before kernel evaluation, using the same scaler fitted during Phase 1.

## P_bubble Post-Selection

After all selections are complete, PC-SAFT bubble-point pressures are computed **once** for every unique pool index appearing across the 30 selections (≤ 300 unique compositions). This avoids redundant PC-SAFT calls for shared compositions.

```python
func = feos.HelmholtzEnergyFunctional.pcsaft(params)   # direct — no EquationOfState wrapper
VLECalculator.compute_bubble_curve(func, [T_K], feed, verbose=False)
```

P_bubble at T_REF = 250 K is stored alongside each selected composition in the output CSVs. This pressure is used by the downstream cDFT calculations to define the T/P integration grid.
